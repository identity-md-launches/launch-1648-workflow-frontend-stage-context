# Repository-only PNG kit

Each finalist directory contains original, monochrome and reversed logomarks at 16, 32, 64, 128, 256, 512, 1024 and 2048 pixels, plus outlined-wordmark and horizontal-lockup PNGs at 512, 1024 and 2048 pixels wide. These 90 PNG files are generated by `node web/scripts/assets.mjs` from the same SVG assets used by the site.

Only one 512 px original-color PNG per finalist is exported to the website. The complete raster kit stays in this source repository to keep the gateway export small. Transparent pixels are intentional. Reversed marks need a dark application surface. SVG masters remain the recommended format for layout and print.

Original artwork is CC0; font software retains its included OFL license. The source mark has not been altered from the deployed art contract.
