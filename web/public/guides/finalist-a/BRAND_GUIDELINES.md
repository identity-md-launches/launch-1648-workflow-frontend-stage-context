# Keystone

## Overview

A shared foundation. A hexagonal frame gathers distinct contributions around a common center. The cross is a meeting point: individual seats adding to one collective identity.

VisualIdentity.md, Edition 1. This is a community proposal for IMD, not official branding. Tone: Direct, grounded and constructive.

### Clear space and minimum size

Use one cross-stroke width (6 units of the 64-unit mark) on every side. 16 CSS pixels for the mark alone; 120 CSS pixels for the horizontal lockup. Test the mark at its actual output size. Use the horizontal lockup when the name must be readable, and the mark alone in square avatars. Align to a layout edge, never against a container border.

### Color variations

Use the original full-color mark on a neutral surface. The supplied one-color version uses ink and negative space; the reversed version uses white and dark negative space. The original deployed mark is preserved exactly. Use indigo for navigation, coral for illustration accents and white for negative space. The cross always remains centered.

### Incorrect usage

Do not rotate the hexagon, stretch its frame, separate the cross, add gradients or recolor individual cross strokes. Do not use the mark as a certification badge, endorsement or official IMD signature.

### Accessible pairings

WCAG 2.2 AA normal text requires 4.5:1, and large text requires 3:1. Ratios below are calculated from sRGB relative luminance.

| Text | Background | Ratio | Usage |
| --- | --- | --- | --- |
| #1F2A6B | #FFFFFF | 13.11:1 | Normal text |
| #FFFFFF | #1F2A6B | 13.11:1 | Normal text |
| #1F2A6B | #F26B4E | 4.36:1 | Large text only |

Tints and accents are for supporting geometry, not body text on white. Never use color alone for errors, selection or voting results. Pair color with a label.

## Typography

Display: **Space Grotesk**, weight 700, licensed under the SIL Open Font License. Text: **DM Sans**, weights 400 and 600, also OFL. Font licenses are included in the website fonts directory. Outlined wordmarks need no installed fonts.

Scale: 14, 16, 20, 28, 40 and 56 px. Body text starts at 16 px with a 1.6 line height. Headings use 1.1–1.2 and sentence case. Keep prose below 70 characters per line. 

Web fallbacks: Space Grotesk, Arial, sans-serif for display; DM Sans, system-ui, sans-serif for text. Host fonts locally, use WOFF2, and retain the font licenses.

## Applications

### Site header

Use the horizontal lockup at 128–180 px wide with the specified clear space. Keep navigation in DM Sans. Separate identity from transaction state: a brand accent never replaces an error message or a disabled control.

### Avatar

Center the mark in a square, keep clear space inside the crop, and inspect at 32 and 64 px. Use the original mark for community profiles and label the context as a proposal.

### Token icon

Use the mark alone, with enough padding to survive a circular crop. The 512 px PNG and favicon are ready for small contexts. Do not add price claims or verification marks.
