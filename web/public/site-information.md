# VisualIdentity.md, Edition 1

An independent community proposal, not official IMD branding. The site loads `imd-deployment.json` and the implementation-derived ABI files it references. This export runs on plain static hosting with a relative base and hash routes.

Frontend source and lockfile are in `web/`. See `web/README.md`, `docs/DESIGN.md` and `docs/frontend/VALIDATION.md` in the source repository for rebuild instructions, design decisions, validation results and limitations. The site is not a third-party audit.

Original artwork, guide documents and frontend source are CC0. Font software retains the included SIL Open Font Licenses; dependencies retain their respective licenses.
